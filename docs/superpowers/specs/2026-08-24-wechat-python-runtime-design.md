# 微信 Python 运行时依赖设计

## 目标

避免微信通道启动后因缺少 `wechatauto` 模块而崩溃。

## 设计

在启动 Python 微信通道前，使用与服务相同的解释器执行 `import wechatauto`。模块不可导入时，以该解释器通过 `pip` 安装仓库中固定的 `wechat_channel/requirements.txt`；安装后再次导入确认。只有确认成功才启动子服务。

安装或复检失败时，通道不启动，并将经过整理的错误传递给现有状态接口。实现不触碰微信客户端、版本安装器或用户配置。

## 测试

用可注入的命令执行器测试：已安装时不执行 pip；缺失时按固定 requirements 安装并复检；安装失败时返回稳定错误。
